Pixelated & Chrome/Metal/Water — 15 arah settings window

Dua dunia visual beda total dari batch doodle sebelumnya. Struktur kontrol tetap sama (toggle, interval, scheduler, idle, status) biar perbandingannya adil — klik tab buat ganti arah, toggle/slider beneran bisa dicoba.

Pixelated

Retro-computing: sudut tegas, border tebal, palet terbatas per era.

Monokrom 4-shade asli layar DMG asli — paling "device-accurate", tapi kontras rendah buat scan cepat di settings yang agak padat.

  • Grid pixel 2px di background, discrete bukan blur.
  • Toggle kotak gak ada radius sama sekali, sesuai estetika LCD kuno.

Hitam + 3 warna saturated ala cartridge NES — paling "arcade", nunjukin status jiggle kayak high score counter.

  • Outline putih tebal 3px di semua kontrol, kontras tinggi gampang dibaca.

Terminal fosfor amber di atas hitam — paling "hacker tool", scanline halus bikin kerasa monitor CRT asli.

  • Scanline + flicker super tipis sebagai satu motion moment, dimatikan kalau reduced-motion.

Bevel 3D klasik Windows 95 — paling "familiar", user Linux lama mungkin langsung kenal interaksinya tanpa belajar ulang.

  • Bevel pakai box-shadow inset berlapis (bukan radius/blur), sesuai era-nya.

Palet vaporwave di grid pixel — paling "estetik medsos", band warna sunset flat bukan gradient halus.

  • Langit di-render pixel-band (canvas), bukan linear-gradient blur.

Chrome / Metal / Water

10 variasi logam, kaca, dan cairan — tiap arah punya gerakan sendiri (specular sweep, glint, shimmer), bukan cuma gradient diam.

Mac OS X Aqua-era — titlebar lampu 3 warna khas, tombol biru glossy. Paling "profesional", cocok kalau mau kesan tool niche tapi matang.

  • Brushed texture = garis horizontal halus digambar, bukan filter generik.

Translucent frosted panel, highlight air di pojok kayak droplet kena cahaya. Paling modern/2026, dekat ke tren "liquid glass".

  • backdrop-filter blur beneran + radial highlight, bukan cuma opacity rendah.

Panel gelap, knob chrome bulat kayak dial dashboard mobil. Paling "serius/mekanik", switch kerasa berat/presisi.

  • Knob pakai radial-gradient buat simulasi specular logam, bukan box-shadow doang.

Blob mercury mengalir pelan di background, dingin dan cair. Paling abstrak/techy, nuansa "neural network UI".

  • Blob di-animate ambient pelan (satu motion moment, respect reduced-motion).

Gradient biru-teal dalam + ripple konsentris pelan. Paling "tenang/calm", pas kalau mau app ini berasa gak intrusive.

  • Ripple digambar ulang per frame via canvas, bukan box-shadow statis.

Panel gelap mewah, switch gradient emas, glint hangat berputar pelan di background. Paling "premium/luxury", kerasa kayak produk niche berbayar.

  • Glint emas orbit radial — posisinya muter pelan terus, gak statis.

Switch-nya sendiri yang "hidup" — gradient pelangi di toggle ON bergeser terus kayak hologram kartu kredit. Paling eye-catching di antara semua chrome.

  • Shimmer-nya CSS background-position animation, bukan canvas — ringan, gak makan CPU.

Gunmetal gelap, switch biru dingin, sweep cahaya tipis lewat pelan dari kiri ke kanan. Paling "netral/profesional" dari semua varian gelap.

  • Sweep highlight lewat tiap ~7 detik, gak ganggu kalau lagi baca teks.

Hampir hitam total, switch ungu redup, glint violet muncul samar lalu ilang. Paling "gelap/minim", cocok kalau tray app ini mau terasa senyap.

  • Glint radial violet orbit sangat lambat (8 detik per putaran) — subtle, bukan dekorasi ribut.

Panel terang baja gosok, switch biru industrial, sweep cahaya diagonal lewat kayak reflection di pipa logam. Satu-satunya chrome dengan bg terang.

  • Garis polish diagonal statis + sweep cahaya bergerak — dua lapis tekstur logam.
